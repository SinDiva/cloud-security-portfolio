# 第 1 週：Linux 基礎指令筆記

環境：Ubuntu 26.04.1 LTS（VMware Workstation Pro），練習資料夾 `~/practice`。

## 1. 路徑

| 符號 | 意思 |
|---|---|
| `/` | 根目錄 |
| `~` | 家目錄（`/home/pan`） |
| `.` | 目前資料夾 |
| `..` | 上一層 |

- 絕對路徑從 `/` 開始，例如 `cd /etc`，在哪裡都到同一處。
- 相對路徑從目前位置開始，例如 `cd practice`。
- 實測：在家目錄打 `cd /practice` 會失敗，因為 `/` 底下沒有 practice；要打 `cd practice` 或 `cd ~/practice`。

## 2. 位置與檔案管理

| 指令 | 作用 | 範例 |
|---|---|---|
| `pwd` | 顯示目前位置 | `pwd` |
| `whoami` | 顯示目前使用者 | `whoami` |
| `ls -la` | 列出所有檔案（含隱藏檔）與詳細資訊 | `ls -la ~/practice` |
| `cd` | 切換資料夾，單獨 `cd` 回家目錄 | `cd ..` |
| `mkdir` | 建立資料夾，`-p` 可一次建多層 | `mkdir -p a/b/c` |
| `touch` | 建立空檔案；已存在則只更新時間 | `touch a.txt b.txt` |
| `cp` | 複製，資料夾要加 `-r` | `cp a.txt logs/` |
| `mv` | 移動或改名，`-i` 覆蓋前會詢問 | `mv -i old.txt new.txt` |
| `rm` | 刪除，沒有資源回收桶 | `rm a.txt` |

## 3. 檢視檔案

| 指令 | 作用 |
|---|---|
| `cat 檔案` | 印出整個檔案，`cat -n` 加行號 |
| `head -n 5 檔案` | 看前 5 行 |
| `tail -n 5 檔案` | 看最後 5 行 |
| `tail -f 檔案` | 即時追蹤新增內容，`Ctrl + C` 結束 |
| `wc -l 檔案` | 計算行數 |
| `less 檔案` | 分頁瀏覽：空白鍵翻頁、`/關鍵字` 搜尋、`q` 離開 |

## 4. 寫入與編輯

| 寫法 | 行為 |
|---|---|
| `echo "文字" > 檔案` | 覆蓋：先清空再寫入 |
| `echo "文字" >> 檔案` | 追加：接在最後面 |
| `echo "文字" \| tee 檔案` | 顯示並覆蓋寫入 |
| `echo "文字" \| tee -a 檔案` | 顯示並追加寫入 |

nano 快捷鍵：`Ctrl + O` 加 Enter 存檔、`Ctrl + X` 離開、`Ctrl + K` 剪下整行、`Ctrl + U` 貼上、`Ctrl + W` 搜尋。

## 5. 常用系統目錄

| 目錄 | 放什麼 |
|---|---|
| `/home` | 使用者個人資料 |
| `/etc` | 系統與軟體設定檔 |
| `/var/log` | 系統日誌 |
| `/tmp` | 暫存檔 |

## 6. 踩坑紀錄（實際遇到的）

| 現象 | 原因 | 解法 |
|---|---|---|
| `cd/`、`cd~`、`echo"..."`、`mv a.txt/A.txt` 失敗 | 指令與參數之間少了空格 | 補上空格 |
| 提示符號變成 `>` 一直等待 | 引號沒有成對 | `Ctrl + C` 取消再重打 |
| `we -l`、`wkdir` 找不到指令 | 指令打錯字 | 用 `Tab` 補全、`↑` 叫出上一個指令 |
| 直接打 `apt.txt` 或 `do apt.txt` 出錯 | 檔名不是指令 | 看內容要用 `cat apt.txt` |
| `echo "..." >> tee apt.txt` 產生了名為 `tee` 的檔案 | `>>` 是導向到檔案，不是接給 tee 的管線 | 要用 `\| tee` |
| `tee -a apt.txt~` 產生 `apt.txt~` | 檔名多打了 `~` | 輸入前檢查檔名，`ls` 確認 |
| 檔案內容被洗掉 | 使用了 `>` 覆蓋 | 要保留原內容就用 `>>` |

## 7. 安全習慣

- `rm` 只在練習資料夾使用，刪除前先 `ls` 確認。
- 修改重要檔案前先備份：`cp 檔案 檔案.bak`。
- 做危險實驗前先拍 VMware 快照。
